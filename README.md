# FishTrack

Консольное Java-приложение для планирования рыбалки,
ведения журнала улова и учёта водоёмов, снастей и приманок.

## Требования

- Java 17 или новее
- Maven 3.9 или новее

## Запуск тестов

`mvn clean test`

## Сборка проекта

`mvn clean package`

## Точка входа

`ru.fishtrack.app.Main`
